# S1-INT-008 · 会员问卷服务

会员空间平台 · 会员问卷：满意度、NPS 与资源对接诉求。

面向约 100 家会员企业对接人的**匿名**问卷：28 题，7 个部分 A–G，另设 1 道可选回访意愿题；预计 ≤ 8 分钟。

## 快速开始

环境：Python 3.11+（本地验证使用 3.13）。

```bash
# 1. 安装依赖
python -m pip install -r requirements.txt

# 2. 生成全部交付物（问卷文档 / 导入文件 / 预览页）
python -m scripts.generate_assets

# 3. 运行测试
python -m pytest tests -q

# 4. 启动服务
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 5. 打开预览与试填计时页
#    http://127.0.0.1:8000/preview

# 6. 端到端验证（需服务已启动；生成证据文件与截图）
python -m scripts.verify_e2e
```

> 所有命令在本目录（`src/`）下执行。配置仅从环境变量读取，见 `app/config.py`。

## 导入文件与平台对接点

交付目录 `../交付物/` 下：

| 文件 | 用途 |
|---|---|
| `问卷导入_问卷星.txt` | 问卷星「文本快速导入」格式，使用官方标记语法（【单选题】【多选题】【量表题|1-5分】【评分题|0-10分】【矩阵量表题|1-5分】【多行填空题】） |
| `问卷导入_问卷星.xlsx` | sheet1「问卷星导入」为官方列；sheet2「腾讯问卷导入」为字段映射；sheet3「题目元数据」含完整元数据 |
| `问卷导入_通用.csv` | UTF-8-BOM，Excel 直接打开不乱码 |

**对接点（需求原文：依赖无）**：

- 本工单**不依赖其他工单接口**，无外部 API/数据库/缓存调用。
- 若后续接入会员中台：A 部分企业画像字段应替换为会员中台聚合接口（仅取行业/规模/年限区间，不取标识）；H1「愿意」名单应由既有会员档案系统线下对接，问卷侧不落联系方式。
- 平台模板可能调整：导入前按腾讯问卷/问卷星当前模板核对列顺序与题型标识；本目录文件已提供字段映射来源。
- 无平台账号，未能在问卷星/腾讯问卷内真实导入并截图；`交付物/预览截图/` 为本地平台样式预览的真实截图。
