## 一、问卷说明

- **匿名承诺**：本问卷不收集企业名称、姓名与任何联系方式；回访意愿题仅表达意愿，由会员经理按既有会员档案线下联系。
- **作答对象**：约 100 家会员企业的对接人。
- **题量**：28 题（要求 20–30 题），分 7 个部分 A–G，另设 1 道可选回访意愿题 H。
- **预计用时**：≤ 8 分钟（以 2 次真实浏览器试填计时验证，见验收报告）。
- **数据用途**：仅用于聚合分析，最小分组样本 n<5 时不展示交叉表。
- **测试数据**：全部为虚构数据，不含任何真实个人或企业信息，文档中不出现客户名称。

### A · 企业画像（匿名，不收集企业名称）

#### A1　贵企业所属的行业是？

- **题型**：单选题
- **选项**：科技/互联网与软件；制造业；金融与投资；专业服务（法律/会计/咨询）；教育培训；医疗健康；文化传媒与创意；零售与消费；物流与供应链；建筑与房地产；能源与环保；其他
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：频数与百分比分布；与 B 满意度、F 续约意向做交叉分析（按行业分组）。
- **说明**：仅收集行业类别，不收集企业名称。

#### A2　贵企业目前的员工规模区间是？

- **题型**：单选题
- **选项**：1–20 人；21–50 人；51–100 人；101–300 人；301–1000 人；1000 人以上
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：频数分布；作为企业规模分层变量，与 NPS、资源需求做交叉分析。

#### A3　贵企业入驻空间的时长区间是？

- **题型**：单选题
- **选项**：不足 6 个月；6–12 个月；1–2 年；2–3 年；3–5 年；5 年以上
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：频数分布；按入驻年限分组比较满意度与续约意向，识别新会员适应期问题。

#### A4　贵企业在空间内日常办公的人数区间是？

- **题型**：单选题
- **选项**：1–5 人；6–10 人；11–20 人；21–50 人；50 人以上
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：频数分布；与实际使用强度相关指标（会议室、活动参与）做交叉分析。

### B · 空间与服务满意度 + NPS

#### B1　您对前台接待的满意度如何？

- **题型**：量表题（1–5 分）
- **选项**：1 = 非常不满意；2 = 不满意；3 = 一般；4 = 满意；5 = 非常满意
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：计算均值、标准差与 4–5 分好评率；纳入满意度分项排行榜。

#### B2　您对会议室（可用性与设施）的满意度如何？

- **题型**：量表题（1–5 分）
- **选项**：1 = 非常不满意；2 = 不满意；3 = 一般；4 = 满意；5 = 非常满意
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：计算均值、标准差与好评率；与 E3 会议室线上预订需求做交叉分析。

#### B3　您对网络（稳定性与速率）的满意度如何？

- **题型**：量表题（1–5 分）
- **选项**：1 = 非常不满意；2 = 不满意；3 = 一般；4 = 满意；5 = 非常满意
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：计算均值与好评率；作为基础设施基线指标按区域/楼层拆分。

#### B4　您对保洁服务的满意度如何？

- **题型**：量表题（1–5 分）
- **选项**：1 = 非常不满意；2 = 不满意；3 = 一般；4 = 满意；5 = 非常满意
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题

#### B5　您对报修响应的满意度如何？

- **选项**：1 = 非常不满意；2 = 不满意；3 = 一般；4 = 满意；5 = 非常满意
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：计算均值与好评率；低分项（1–2 分）进入服务改进清单。

#### B6　您对活动组织的满意度如何？

- **题型**：量表题（1–5 分）
- **选项**：1 = 非常不满意；2 = 不满意；3 = 一般；4 = 满意；5 = 非常满意
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：计算均值与好评率；与 D1 参与频次、D2 偏好类型做交叉分析。

#### B7　您对会员经理服务的满意度如何？

- **题型**：量表题（1–5 分）
- **选项**：1 = 非常不满意；2 = 不满意；3 = 一般；4 = 满意；5 = 非常满意
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：计算均值与好评率；与 F1 续约意向做相关性分析。

#### B8　您对公共区域与安保的满意度如何？

- **题型**：量表题（1–5 分）
- **选项**：1 = 非常不满意；2 = 不满意；3 = 一般；4 = 满意；5 = 非常满意
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：计算均值与好评率；纳入物业服务分项对比。

#### B9　您有多大可能将本空间推荐给其他企业？

- **题型**：NPS 评分题（0–10 分）
- **选项**：0 = 完全不会推荐；1；2；3；4；5 = 中立；6；7；8；9；10 = 一定会推荐
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：按推荐者(9–10)/中立者(7–8)/贬损者(0–6)分组，计算 NPS = 推荐者占比 − 贬损者占比；并与 B1–B8 分项满意度做驱动因素分析。详见《NPS计算说明.md》。

### C · 资源对接需求

#### C1　您希望对接的资源类型有哪些？（最多选 3 项）

- **题型**：多选题
- **选项**：客户；供应商；投资；人才；政策；专家
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：各选项选择率（多选口径，分母为有效答卷数）；与行业(A1)、规模(A2)交叉分析。
- **说明**：最多选 3 项，导入平台时设置多选上限。

#### C2　过去 12 个月，贵企业是否通过空间获得过资源对接？

- **题型**：单选题
- **选项**：是；否；不确定/记不清
- **是否必填**：是
- **跳转逻辑**：选择“否”或“不确定/记不清” → 跳至 D1；选择“是” → 进入 C3。
- **分析方式**：计算对接获得率；作为 C3 的显示条件与资源对接成效的核心分母。

#### C3　您对过去 12 个月通过空间获得的对接效果如何评价？

- **题型**：单选题
- **选项**：很有帮助；有帮助；一般；帮助不大；没有帮助
- **是否必填**：是
- **跳转逻辑**：仅当 C2=“是”时作答；否则跳过本题。
- **分析方式**：频数分布；计算“很有帮助+有帮助”占比作为对接有效率；与 C1 资源类型交叉分析。

### D · 活动与内容

#### D1　贵企业参加空间活动的频次是？

- **题型**：单选题
- **选项**：每周一次及以上；每月 1–2 次；每季度 1–2 次；半年 1–2 次；几乎不参加
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：频数分布；与 B6 活动满意度、F1 续约意向做交叉分析。

#### D2　您偏好的活动类型有哪些？（最多选 3 项）

- **题型**：多选题
- **选项**：行业论坛/峰会；技术/业务培训；投融资路演；社交沙龙；政策解读；创始人分享；其他
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：各选项选择率；据此排定活动类型优先级。

#### D3　您偏好的活动时段有哪些？（可多选）

- **题型**：多选题
- **选项**：工作日午间；工作日晚间；周末白天；周末晚间
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：各时段选择率；与 D1 参与频次交叉分析以确定排期。

#### D4　您对以下内容的兴趣程度如何？

- **题型**：矩阵量表题（1–5 分）
- **选项**：1 = 完全不感兴趣；2 = 不太感兴趣；3 = 一般；4 = 比较感兴趣；5 = 非常感兴趣
- **矩阵子项**：创始人播客；行业知识内容
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：逐项计算均值与高兴趣(4–5 分)占比；作为内容生产投入依据。

### E · 数字化触点

#### E1　您是否使用过空间的现有小程序？

- **题型**：单选题
- **选项**：经常使用；偶尔使用；听说过但未使用；不知道有小程序
- **是否必填**：是
- **跳转逻辑**：选择“经常使用”或“偶尔使用” → 进入 E2；否则 → 跳至 E3。
- **分析方式**：使用率（经常+偶尔）与触达缺口（未使用+不知道）占比。

#### E2　您常用小程序的哪些功能？（可多选）

- **题型**：多选题
- **选项**：会议室预订；报修；账单查看；访客邀请；活动报名；其他
- **是否必填**：是
- **跳转逻辑**：仅当 E1=“经常使用”或“偶尔使用”时作答；否则跳过本题。
- **分析方式**：各功能使用率；与 B2/B5/B6 分项满意度做交叉分析，识别高频低分触点。

#### E3　您希望在小程序上办理哪些事项？（最多选 5 项）

- **题型**：多选题
- **选项**：会议室预订；报修；账单查看；访客邀请；活动报名；其他
- **是否必填**：是
- **跳转逻辑**：无条件进入下一题
- **分析方式**：各事项需求率；与 E2 使用率做差距分析，输出数字化排期清单。
